# LayoutGlow

Индикатор раскладки клавиатуры для macOS: цветное свечение вдоль нижнего края экрана (в районе дока).

- RU — оранжевое свечение
- EN (ABC) — приглушённое синее
- При переключении полоса вспыхивает ярче и на секунду появляется плашка RU/EN над доком

Работает поверх дока на всех мониторах и во всех Spaces, клики не перехватывает, иконки в доке нет. Автозапуск при входе приложение включает себе само (Login Item) при первом запуске.

## Быстрое переключение по Fn

Встроено быстрое переключение раскладки по тапу Fn/🌐 — без системной задержки. Комбинации Fn+стрелки и Fn+F-клавиши не затрагиваются (тап засчитывается только если Fn отпущен без других клавиш и держался меньше 0.6 c).

Чтобы заработало, нужно два шага:

1. Выдать разрешение: System Settings → Privacy & Security → Input Monitoring → включить LayoutGlow (приложение само запросит при первом запуске). Если после выдачи не заработало — перезапустить приложение.
2. System Settings → Keyboard → «Press 🌐 key to» → **Do Nothing**. Пока там стоит «Change Input Source», LayoutGlow не вмешивается, чтобы не переключать дважды, и работает штатное медленное переключение.

Отключить функцию совсем: `fnSwitchEnabled = false` в начале `main.swift` и `./install.sh`.

## Режим Punto/Caramba

Автоисправление слова, набранного не в той раскладке: на пробеле слово проверяется системным спеллчекером; если в текущем языке это мусор («ghbdtn»), а в другой раскладке — валидное слово («привет»), оно автоматически стирается, перепечатывается правильно и раскладка переключается.

Ручная конвертация: **двойной тап Shift** — конвертировать слово, которое сейчас набираешь, или последнее набранное. Повторный двойной Shift откатывает (в том числе автоисправление).

Что нужно: разрешение Accessibility (System Settings → Privacy & Security → Accessibility → LayoutGlow; приложение запросит само).

Ограничения и защиты:

- Пароли в безопасности: в secure-полях macOS вообще не отдаёт нажатия приложениям.
- В терминалах (Terminal, iTerm2, Warp, kitty, Ghostty, WezTerm) автоисправление молчит; список — `excludedBundleIDs` в `main.swift`. Двойной Shift работает везде.
- Автоисправление срабатывает только на пробеле; через Enter/Tab/стрелки/клик мышью слово не трогается.
- Слова короче 3 букв не исправляются.

Выключить: `autoCorrectEnabled = false` (авто) и/или `manualConvertEnabled = false` (двойной Shift) в начале `main.swift`, затем `./install.sh`.

Нюанс: приложение подписано ad-hoc, поэтому после пересборки (`install.sh` после правки настроек) macOS может снова спросить разрешения Input Monitoring и Accessibility.

## Перенос на другой мак

Скопировать `LayoutGlow.dmg`, открыть, перетащить LayoutGlow.app в Applications, запустить один раз. Всё.

Если macOS заблокирует запуск (приложение без нотаризации): System Settings → Privacy & Security → «Open Anyway», либо в терминале:

```bash
xattr -cr /Applications/LayoutGlow.app
```

Требование: мак той же архитектуры (Apple Silicon), macOS 13+.

## Скрипты

- `./install.sh` — собрать и установить на этом маке (после правки настроек запустить снова)
- `./build-dmg.sh` — только собрать `LayoutGlow.dmg`
- `./uninstall.sh` — полностью удалить

## Настройка

Цвета, яркость (`alpha`), высота полосы (`glowHeight`) и время жизни плашки — в начале `main.swift`. После правки: `./install.sh` (и `./build-dmg.sh` уже входит в него — DMG пересоберётся тоже).

## Выключить автозапуск

System Settings → General → Login Items → убрать LayoutGlow, либо `./uninstall.sh`.
