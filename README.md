# LayoutGlow

Индикатор раскладки клавиатуры для macOS: цветное свечение вдоль нижнего края экрана (в районе дока).

- RU — оранжевое свечение
- EN (ABC) — приглушённое синее
- При переключении полоса вспыхивает ярче и на секунду появляется плашка RU/EN над доком

Работает поверх дока на всех мониторах и во всех Spaces, клики не перехватывает, иконки в доке нет, системных разрешений не требует. Автозапуск при входе приложение включает себе само (Login Item) при первом запуске.

## Перенос на другой мак

Скопировать `LayoutGlow.dmg`, открыть, перетащить LayoutGlow.app в Applications, запустить один раз. Всё.

Если macOS заблокирует запуск (приложение без нотаризации): System Settings → Privacy & Security → «Open Anyway», либо в терминале:

```bash
xattr -cr /Applications/LayoutGlow.app
```

Требование: мак той же архитектуры (Apple Silicon), macOS 13+.

## Скрипты

- `./install.sh` — собрать и установить на этом маке (после правки настроек запустить снова)
- `./build-dmg.sh` — только собрать `LayoutGlow.dmg`
- `./uninstall.sh` — полностью удалить

## Настройка

Цвета, яркость (`alpha`), высота полосы (`glowHeight`) и время жизни плашки — в начале `main.swift`. После правки: `./install.sh` (и `./build-dmg.sh` уже входит в него — DMG пересоберётся тоже).

## Выключить автозапуск

System Settings → General → Login Items → убрать LayoutGlow, либо `./uninstall.sh`.
