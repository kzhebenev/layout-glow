# LayoutGlow

Индикатор раскладки для macOS, быстрое переключение, режим Punto/Caramba и быстрые вставки.

- Цветное свечение вдоль нижнего края экрана: RU — оранжевое, EN — синее, Caps Lock — красное
- Точка того же цвета у текстового курсора в момент переключения
- Иконка в меню-баре с текущей раскладкой и всеми настройками
- Быстрое переключение по тапу Fn (Globe) — без системной задержки
- Автоисправление слова, набранного не в той раскладке
- Своя раскладка для каждого приложения
- Вставки часто набираемого текста по Cmd+Option+цифра

Работает поверх дока на всех мониторах и во всех Spaces, клики не перехватывает, иконки в доке нет. Автозапуск при входе включается сам при первом запуске.

## Установка

Скачать `LayoutGlow.dmg` из [релизов](https://github.com/kzhebenev/layout-glow/releases/latest), перетащить LayoutGlow.app в Applications, запустить. Дальше приложение обновляется само: проверяет релизы при запуске и по пункту меню.

Либо из исходников (нужны Xcode Command Line Tools):

```bash
git clone https://github.com/kzhebenev/layout-glow && cd layout-glow && ./install.sh
```

Выдать два разрешения (приложение запросит само, статус виден в меню):

- **Privacy & Security → Input Monitoring** — чтобы ловить тап Fn и набираемые слова
- **Privacy & Security → Accessibility** — чтобы перепечатывать текст и находить курсор

И для быстрого Fn: **Keyboard → «Press Globe key to» → Do Nothing**.

## Жесты

| Жест | Что делает |
| --- | --- |
| Тап Fn | Переключить раскладку мгновенно |
| Двойной Shift | Конвертировать выделенное, а без выделения — текущее или последнее слово |
| Cmd+Option+0 | Развернуть набранный ключ в текст из словаря вставок |
| Cmd+Option+1...9 | Вставить строку из соответствующего слота |

## Словари

Лежат в `~/Library/Application Support/LayoutGlow`, открываются из меню («Словари»), перечитываются автоматически при изменении.

- `exceptions.txt` — слова, которые автоисправление не трогает. Пополняется само: откат исправления двойным Shift заносит слово сюда навсегда.
- `commands.txt` — системные команды unix и macOS (245 штук из коробки). Нужен потому, что спеллчекер их не знает: без словаря «лгиусед» не превратится в «kubectl».
- `snippets.txt` — вставки в формате `ключ = текст`. Ключ `кж` разворачивается в «Константин Жебенев» по Cmd+Option+0; числовые ключи `1`...`9` вставляются по Cmd+Option+цифра.

## Что автоисправление не трогает

Пароли (в secure-полях система не отдаёт нажатия никому), приложения из списка исключений, строки с цифрами, точками и слэшами (пути, домены, команды с аргументами), аббревиатуры сплошными заглавными, слова из `exceptions.txt`. Срабатывает только на пробеле — после Enter текст уже не меняется.

Короткие слова исправляются: двухбуквенные по словарю, однобуквенные по списку (я, в, и, к, с, у, а, о; a, i), потому что спеллчекер считает валидной любую одиночную букву. Слова через дефис и апостроф разбираются по частям.

## Диагностика

```bash
cat "$HOME/Library/Application Support/LayoutGlow/status.log"
```

Состояние разрешений, счётчики нажатий и последние решения с причинами: почему конкретное слово было пропущено или исправлено.

## Разработка

- `./run-tests.sh` — тесты логики исправления и словарей (35 проверок)
- `./install.sh` — собрать и установить
- `./build-dmg.sh` — собрать `LayoutGlow.dmg`
- `./setup-signing.sh` — создать постоянный самоподписанный сертификат; без него macOS сбрасывает выданные разрешения после каждой пересборки (вызывается автоматически)
- `./uninstall.sh` — удалить приложение

`Core.swift` — логика раскладок, разбора слов и словарей, покрытая тестами. `main.swift` — приложение: окна свечения, меню, перехват клавиатуры, вставки, обновления. Внешний вид правится константами в начале `main.swift`, остальное настраивается в меню.
