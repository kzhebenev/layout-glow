# LayoutGlow

Индикатор раскладки клавиатуры для macOS плюс быстрое переключение и режим Punto/Caramba.

- Цветное свечение вдоль нижнего края экрана: RU — оранжевое, EN — приглушённое синее
- При переключении полоса вспыхивает и на секунду появляется плашка RU/EN над доком
- Иконка в меню-баре показывает текущую раскладку и содержит все настройки
- Быстрое переключение по тапу Fn (Globe) — без системной задержки
- Автоисправление слова, набранного не в той раскладке, и конвертация по двойному Shift

Работает поверх дока на всех мониторах и во всех Spaces, клики не перехватывает, иконки в доке нет. Автозапуск при входе включается сам при первом запуске.

## Установка

Скачать `LayoutGlow.dmg` из [релизов](https://github.com/kzhebenev/layout-glow/releases), перетащить LayoutGlow.app в Applications, запустить.

Либо из исходников (нужны Xcode Command Line Tools):

```bash
git clone https://github.com/kzhebenev/layout-glow && cd layout-glow && ./install.sh
```

Дальше выдать два разрешения (приложение запросит само, статус виден в меню-баре):

- **Privacy & Security → Input Monitoring** — чтобы ловить тап Fn и набираемые слова
- **Privacy & Security → Accessibility** — чтобы перепечатывать исправленное слово

И для быстрого Fn: **Keyboard → «Press Globe key to» → Do Nothing** (пока там «Change Input Source», LayoutGlow не вмешивается, чтобы не переключать дважды).

## Меню-бар

- Переключатели: быстрый Fn, автоисправление, конвертация по двойному Shift
- «Автоисправление в «<приложение>»» — выключить или включить для того приложения, которым пользовался последним (терминалы, Termius, что угодно)
- Списки исключений: приложения и слова, любое можно убрать
- Статус разрешений — клик открывает нужный раздел системных настроек

## Режим Punto/Caramba

Набрал «ghbdtn» и нажал пробел — слово проверяется системным спеллчекером; если в текущем языке это мусор, а в другой раскладке валидное слово, оно стирается, перепечатывается правильно и раскладка переключается.

**Двойной тап Shift**:

- есть выделенный текст — конвертируется он целиком, любой длины
- иначе конвертируется слово, которое набираешь сейчас, или последнее набранное
- если это откат только что сработавшего автоисправления, слово навсегда уходит в исключения (самообучение)

Защиты: пароли не видны приложению (secure input), автоисправление молчит в терминалах из списка, срабатывает только на пробеле (не на Enter), пропускает слова короче 3 букв, аббревиатуры сплошными заглавными (HD, СКЗИ) и слова из списка исключений.

## Разработка

- `./install.sh` — собрать и установить (после правки настроек в `main.swift`)
- `./build-dmg.sh` — собрать `LayoutGlow.dmg`
- `./setup-signing.sh` — создать постоянный самоподписанный сертификат (вызывается автоматически при первой сборке; без него macOS сбрасывает выданные разрешения после каждой пересборки)
- `./uninstall.sh` — удалить приложение

Внешний вид (цвета, высота полосы, длительности) правится константами в начале `main.swift`. Функциональные настройки менять в коде не нужно — они в меню-баре.
